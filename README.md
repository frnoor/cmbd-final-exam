🛡️ Project Description
This repository contains a sanitized penetration testing report and methodology walkthrough created during a full-scope black box assessment. The engagement progressed from initial reconnaissance to privilege escalation on a Linux-based target.

🎯 Assessment Scope
- Target: Metadata-driven internal network asset (Anonymized)
- Goal: Identify entry vectors and escalate privileges
- Outcome: Administrative (root-level) access achieved

🛠️ Methodology
The assessment followed industry-standard frameworks:

- Penetration Testing Execution Standard (PTES)
- OWASP Web Security Testing Guide (WSTG)

⚖️ Ethical Disclaimer
All data, IP addresses, and credentials have been anonymized. This project is for educational and portfolio purposes only. Unauthorized use of these techniques against live systems without prior written consent is illegal.
